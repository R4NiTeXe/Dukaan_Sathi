# AI-Powered Voice Billing Platform

**Repository:** [https://github.com/R4NiTeXe/AI-Billing.git](https://github.com/R4NiTeXe/AI-Billing.git)

An AI-powered web platform designed to help small local shop owners manage daily billing and understand their business through voice-based interactions and intelligent analytics.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS v4
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **AI:** Gemini API
- **Media Storage:** Cloudinary

## Project Structure
- `/client` - Frontend React application
- `/server` - Backend Express application
- `/docs` - Project documentation and architecture details
